# OWASP Dependency-Track

SBOM / SCA platform for tracking vulnerabilities in dependencies.

## Usage
```bash
vagrant up
# Wait 2-3 minutes for startup
```

## Quick start
1. Login and change default password
2. Projects → Create Project
3. Upload a CycloneDX or SPDX SBOM file
4. View identified vulnerabilities and policy violations
